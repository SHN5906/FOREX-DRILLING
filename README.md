# Forex Drilling

Site de [Forex Drilling](https://forexdrilling.com), contracteur de forage spécialisé, Singapour et Papouasie-Nouvelle-Guinée.

Pages : accueil, à propos, services, flotte, projets, qualité, HSE, contact.

> Ce dépôt est une copie figée. Le développement se poursuit dans [forex-drilling-dev/FOREX-DRILLING](https://github.com/forex-drilling-dev/FOREX-DRILLING).

## Stack

Next.js 16 (App Router), React 19, TypeScript strict, Tailwind CSS v4, Framer Motion, Three.js.

## Démarrer en local

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Autres commandes : `pnpm build` (optimise les images puis compile) et `pnpm lint`.
